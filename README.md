# OpenChat for Apple Watch v2.1 - "The Companion Update" 🤝✨

在 v2.0 奠定了记忆与云端能力的基础上，**v2.1** 聚焦于一个核心目标：让 AI 真正了解「你是谁」，并让 iPhone 与 Apple Watch 之间的体验无缝融为一体。

---

## 🌟 核心亮点

### 1. 👤 个人身份系统 (Personal Identity)
> "终于，AI 知道你叫什么，也认识你的脸。"

- **自定义名称**：在设置中填写你的名字，AI 在对话中会自然地称呼你。
- **自定义头像**：上传你的照片作为头像，界面更有温度、更个性化。
- **浅色 / 深色 / 跟随系统**：新增全局外观模式切换，不再强制深色。

---

### 2. 🗑️ 记忆回收站 (Memory Trash)
> "删错了记忆？别担心，还能找回来。"

- **软删除机制**：删除记忆不再是一锤子买卖，会先移入回收站。
- **一键恢复**：误删的记忆可从回收站还原，不再丢失重要信息。
- **永久删除**：在回收站中确认后方可彻底清除，双重保险。
- **清空回收站**：一键清理，释放空间。
- **删除确认弹窗**：防止误触，重要操作前二次确认。

---

### 3. ⌚ 完整的 iPhone ↔ Apple Watch 双向同步 (Full Sync)
> "两台设备，一个你。"

- **全量双向同步**：iPhone 端的所有配置（供应商、聊天、记忆、偏好设置）现在都能完整同步到 Apple Watch，反之亦然。
- **修复了关键同步盲区**：v2.0 中 Watch 端存在若干偏好设置（外观/用户名/头像等）仅写入磁盘但从不读取的 bug，本版全部修正。
- **回收站跨端同步**：在 iPhone 恢复或清空记忆，Watch 端实时生效。

---

### 4. 🥷 隐身模式 (Incognito Mode)
> "聊过就算，不留记录。"

- **零写入**：开启隐身模式后，当前对话的所有消息不会写入磁盘，关闭 App 后自动消失。
- **快速切换**：在侧边栏中一键开启/关闭，状态图标实时反映当前模式。

---

### 5. ✏️ 聊天记录管理增强
- **重命名会话**：长按或滑动对话，可自定义会话标题，方便归档管理。
- **性能大幅优化**：启动时将数据加载移至后台线程，彻底解决 iOS/watchOS 开启时卡顿转圈的问题。

---

### 6. 🌐 联网搜索 (Web Search) `v2.3`
> "不只是记忆，还有实时的世界。"

- **实时搜索增强**：接入自建 Serper 代理，在对话中获取最新新闻、天气、知识。
- **辅助模型提取关键词**：自动从你的问题中提炼搜索词，结果更精准。
- **搜索鉴权**：支持为搜索 Worker 配置独立认证密钥，更安全。
- **上下文注入**：搜索结果自动注入对话上下文，AI 回答有理有据。

---

### 7. 🧠 记忆系统全面升级 `v2.4 / v2.5`
- **记忆活动追踪**：每次对话后，可查看本轮「调用了哪些记忆」「新增了什么记忆」。
- **记忆药丸标签**：以优雅的药丸标签样式展示本轮记忆活动，信息密度与美观兼顾。
- **更智能的提取逻辑**：只将用户消息传给提取模型，防止 AI 自己说的话被误判为用户事实（幻觉污染）。
- **记忆合并去重**：辅助模型自动合并语义相似的记忆条目，保持记忆库精简。
- **相似度阈值可调**：在设置中自定义记忆检索的相似度门槛（默认 0.1）。
- **最大检索数可调**：控制每次对话注入的记忆上限（默认 5 条）。
- **Worker 格式兼容增强**：同时支持 OpenAI 格式 `{"data": [{"embedding": [...]}]}` 和旧版 `{"data": [[...]]}` 两种返回格式。

---

### 8. ⚡ 性能与稳定性 `v2.6 / v2.8 / v2.9`
- **滚动丝滑优化**：改回字符级别监听 + 50ms 节流，彻底消除流式输出时的页面弹跳抖动。
- **辅助模型自动压缩上下文**：当对话历史超过 8000 字符时，自动调用辅助模型生成高密度摘要，节省 Token 同时保留关键语境。
- **记忆合并阈值提升**：提高去重标准（v2.8），防止仅有微弱关联的记忆被误合并，保证记忆准确性。
- **Markdown 流式渲染重写**：全程 Substring 索引，避免频繁字符串拷贝，高对话量下稳定无 OOM。
- **思考过程过滤增强**：自动过滤空白思考块，防止出现空白「思考过程」气泡。

## 🚀 升级指南

1. **安装 IPA**：通过 AltStore / Sideloadly / TrollStore 安装 `OpenChat_v2.1.ipa`。
2. **自动同步**：安装完成后，手机与手表数据将自动同步，无需手动操作。
3. **可选：配置联网搜索**：在「设置 → 联网搜索」中填入你的 Serper Worker URL 和认证密钥。
4. **可选：配置记忆参数**：在「设置 → 记忆功能」中按需调整检索数量与相似度阈值。
